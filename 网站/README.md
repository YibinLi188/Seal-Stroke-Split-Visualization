# 拆笔画可视化网站

这是 `拆笔画修改` 项目的本地可视化前端。它直接读取项目中“修改后的程序的结果”，并通过同一套 Python 算法分析上传的金文图片。

## 启动

最省事的方式是双击 `启动网站.bat`，它会启动服务并打开浏览器。

也可以在本目录打开 PowerShell：

```powershell
python server.py
```

然后打开：<http://127.0.0.1:8766>

不需要 npm、Node.js 或额外前端构建步骤。Python 环境需要已有项目使用的 `numpy` 和 `Pillow`。

## 功能

- 浏览项目内置的金文样例及其拆解结果。
- 使用彩色单笔图层逐笔播放、暂停、重置、前进和后退。
- 切换输入原图与笔画叠加结果总览。
- 上传 PNG、JPG、JPEG 或 WebP，调用修改后的拆笔画程序生成结果。
- 用 `prefers-reduced-motion` 兼容减少动态效果的系统设置。
